# Política de seguridad

## Alcance
Este repositorio contiene el código de la web estática de la tesis doctoral de Alejandro Baeza (Str3Dlok), publicada con GitHub Pages en https://str3dlok.github.io. No procesa datos de usuarios ni usa formularios, y la web pública no carga dependencias de terceros en el navegador. El gestor de contenidos (`/admin/`) carga Sveltia CMS desde unpkg.com y solo lo usa quien tiene acceso de escritura al repositorio.

## Cómo informar de una vulnerabilidad
Por favor, no abras una incidencia pública. Usa la opción **"Report a vulnerability"** de la pestaña *Security* de este repositorio (informe privado) o escribe a **str3dlok@gmail.com** indicando:

- Descripción del problema y página afectada.
- Pasos para reproducirlo.
- Posible impacto.

Recibirás respuesta en un plazo aproximado de 7 días.
